# Support

`docx-tool` is community-maintained open-source software.

Before opening an issue:

1. Read the [README](README.md) and run `docx-tool doctor --json`.
2. Check existing issues and confirm the problem on the latest release.
3. Reduce the problem to a synthetic DOCX with no private data.

Use the bug-report template for reproducible defects and the feature-request
template for scoped proposals. Include the tool version, Python version,
operating system, installation method, exact command, exit code, and sanitized
output.

Do not use public issues for vulnerabilities or confidential documents. Follow
[SECURITY.md](SECURITY.md) instead. There is no guaranteed response time or
private consulting support.
